# Frequently asked questions

**What is Sakthi's strongest project?**
ATTS-RAG for AI and security work: a fully local RAG system with three security layers and sentence-by-sentence answer verification. The Healthcare Appointment Manager for backend and distributed-systems work: Redis distributed locks, a transactional outbox and 137 tests.

**Which languages does Sakthi use most?**
Python (FastAPI) and Java (Spring Boot) for backends, TypeScript/JavaScript with React for frontends. Also Go, Solidity and Dart/Flutter.

**Has Sakthi worked with LLMs?**
Yes. ATTS-RAG runs Llama 3 locally through Ollama with hybrid retrieval, reranking and NLI-based answer verification. The Medical Miscommunication Detector uses a language model limited to vetted definitions. This portfolio's chatbot runs on Google Gemini.

**Does Sakthi work in teams?**
Yes. The Relational-to-NoSQL Schema Migration Tool was built with Anish Jaiswal and Savar Gambhir. ChainJudge was an undergraduate capstone project.

**How was this website built?**
Next.js (App Router), TypeScript, Tailwind CSS and Framer Motion, hosted on Vercel. The "Ask Sakthi" chatbot uses Google Gemini with the whole portfolio content as its knowledge base, and it can scroll the page, open projects and filter the project grid using function calling.
