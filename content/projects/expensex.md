An offline-first expense tracker built phase by phase as a structured Flutter curriculum.

- **Phase 1** is a pure-Dart package (`expensex_core`) with no Flutter or database: real totals, a "Safe-to-Spend" figure and anomaly detection over seed data, all covered by tests.
- Later phases add the Flutter UI on top of the same domain layer, unchanged.
